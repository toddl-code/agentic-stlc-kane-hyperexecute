# [2.0.0] - 2026-05-26

Major release introducing URL-prefix session isolation. Every task-operating
endpoint is now reachable under both the original unprefixed form
(`/tasks`, `/archive`, etc.) and a session-prefixed form
(`/s/<session_id>/tasks`, `/s/<session_id>/archive`, etc.). All v1.x behavior
is preserved within each session, providing data separation for parallel
automation.

## Added

- User can access TaskFlow under a session-prefixed URL of the form /s/<session_id>/tasks where session_id is a 32-character lowercase hex UUID
- User visiting a fresh session URL sees an empty task list with the create form available; the session is created implicitly on first write with no signup required
- User visiting a URL with a malformed session ID (not the literal "default" and not a 32-character lowercase hex string) receives an HTTP 404 response
- Tasks, archives, labels, and priorities created under one session are invisible and untouchable from any other session

## Changed

- Task list and Archive page now reflect only data from the active session
- The "Archive completed" bulk action and its count reflect only completed tasks in the active session
