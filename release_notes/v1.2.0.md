# [1.2.0] - 2026-05-18

Third release of TaskFlow. Adds task priority, a bulk "Archive completed"
action, and a secondary sort that surfaces higher-priority work after due
date.

## Added

- User can set a task's priority to High, Medium, or Low (or leave it unset)
- User can change a task's priority on the edit screen
- User can archive all completed tasks in one click via an "Archive completed" button at the bottom of the task list

## Changed

- Task list sort now uses priority as a secondary key after due date (High → Med → Low → unset)
- The label cell in the task list now also displays the priority chip when set
